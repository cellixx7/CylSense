# v0.2 - Estado anterior, impacto e verificacao

## Estado encontrado (2026-10-13, antes da v0.2)

- Monorepo pnpm com um unico workspace: `apps/desktop` (Tauri 2.12, React 19, Vite 6, Tailwind 4, um componente shadcn, 3 testes).
- Sem `packages/`, Zod, backend ou web. ESLint e Prettier ausentes.
- P0-01 concluido: `pnpm dev` e `pnpm build` validados no Windows (ver [p0-01-aceite.md](p0-01-aceite.md)).

## Impacto sobre o P0-01

| Item | Impacto |
|---|---|
| Codigo do desktop (`apps/desktop/**`) | Nenhum arquivo alterado |
| Scripts `dev`, `dev:web`, `build`, `build:web` | Mantidos com o mesmo comportamento (apontam para o desktop) |
| `pnpm typecheck` / `pnpm test` | Agora tambem cobrem os novos workspaces |
| `pnpm-workspace.yaml` | Passa a incluir `services/*` e `packages/game-adapters/*` |
| `engines.node` | `>=20` -> `>=22.9` (flag `--env-file-if-exists` da API; Node 20 fora de suporte) |
| `.gitignore` | `.next/`, `next-env.d.ts`, `*.tsbuildinfo`; excecao para `services/api/.env.mock` (sem segredos) |

Atencao: `dev:web` continua sendo o **front-end do desktop** no navegador, por compatibilidade. O site e `dev:site`.

## Migracoes

Nenhuma migracao de dados: ainda nao ha banco (SQLite e o P0-03, PostgreSQL e futuro).
